## 📖 概要

反射神経テスト・色違い当て・数字記憶の3つのミニゲーム詰め合わせです。ビルド不要の静的サイトで、ブラウザだけで動きます。トップ画面でゲームを選び、画面遷移なしで切り替えて遊べます。

## ✨ 機能

### ⚡ 反射神経テスト
- 「タップしてスタート」→ 赤い「待って…」画面 → ランダムなタイミング（1.2〜5.0秒）で緑に変わったら即タップ。
- 反応時間をミリ秒で表示。全5回の平均とベストを集計し、記録一覧も表示します。
- 緑になる前に押すとフライング（その回はやり直し）。

### 🎨 色違い当て
- 制限時間60秒。グリッドの中から1マスだけ色の違うマスをタップします。
- 正解 +1点、ミス -2点（減点）。
- 正解するほど難易度アップ: グリッドが 3×3 → 4×4 → 5×5 → 6×6 に増え、色の差が少しずつ小さくなります（レベル1〜10）。

### 🔢 数字記憶
- 数字列が数秒だけ表示されるので覚えて、隠れたら入力して答えます。
- 表示時間は桁数に応じて少しずつ長くなります（桁数×0.6+1秒）。
- 正解するごとに桁数が1つ増え、間違えたら終了。到達した桁数がスコアです。

## 📝 使い方

1. `index.html` をブラウザで開く（または静的ホスティングに配置する）。
2. トップで遊びたいゲームの「あそぶ」を押します。各ゲーム画面の「← トップへ」で戻れます。

## 🪟 Windows 版

`windows/` フォルダに、同じ内容の Windows アプリ（.NET 8 / WinForms）があります。Web 版の3ゲーム（反射神経テスト／色違い当て／数字記憶）をすべて収録し、ルール・難易度調整・スコア仕様も Web 版と同じです。ベストスコアは端末内のファイル（`%LocalAppData%\Chibigame\best.txt`）に保存します。

- ビルド: `windows/build.bat`（Windows）または `windows/build.sh` で `windows/dist/Chibigame.exe` を生成（成果物は git には含めません）

## 📋 技術メモ

- 素の HTML/CSS/JS のみ。外部リソース・ライブラリ不使用、フォントはシステムの日本語フォントスタック。
- ルール計算（難易度・集計・判定）は `js/game-core.js` に分離し、Node の単体テスト（`npm test`）で検証します。`app.js` は画面の配線だけを担当します。
- 反射神経の計測は `performance.now()` ベース。タップは `pointerdown` で受けて遅延を最小化しています。
- 色違い当ての色は HSL で生成し、難易度は明度差（ΔL）を段階的に縮小して調整します。
- テーマはダーク基調で、トップバーのボタンからライトへ切り替えできます（保存キー `chibigame-theme`）。
- PWA 対応: `manifest.webmanifest` と Service Worker（`sw.js`、キャッシュ名 `chibigame-v1`、同一オリジンGETをキャッシュ）でオフラインでも動作し、ホーム画面に追加できます。

### スコア保存

- 各ゲームのベストスコア（反射神経は平均とベスト1回、色違いはスコア、数字記憶は到達桁数）を localStorage に保存し、トップ画面に表示します。
- 保存キーは `chibigame_best_reaction_avg` / `chibigame_best_reaction` / `chibigame_best_color` / `chibigame_best_memory` です。
- 保存値が数値でない場合（ストレージ破損・手動編集など）は「記録なし」として扱い、次のプレイで正しい記録に自己回復します。
- スコアは端末内にのみ保存され、外部送信はしません。

## 📁 ファイル構成

```
index.html            画面（トップ／各ゲーム）
style.css             スタイル（モバイルファースト、ダーク基調＋ライト切替）
app.js                画面の配線（3ゲームの操作・表示）
js/game-core.js       ルール計算の中核（DOM 非依存、テスト対象）
test/                 ロジック中核の単体テスト（node:test）
sw.js                 Service Worker
manifest.webmanifest  PWAマニフェスト
icons/                アイコン（192 / 512）
windows/              Windows 版（.NET 8 / WinForms）
```
